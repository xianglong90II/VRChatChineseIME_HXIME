# HXIME — VRChat Chinese IME

HXIME 是用于 VRChat 世界的中文输入法与键盘，支持全拼、简拼、混拼、中英文切换以及简体/繁体切换，并支持自定义界面皮肤。

## 使用方法

1. 将 `Assets/HX2xianglong90/HXIME/HXIME_Pinyin.prefab` 拖入 Unity 场景。
2. 在预制件的 `HXIMEUI` 组件中指定目标输入框。
3. 根据需要调整输入法手柄和键盘的位置、皮肤顺序。

详细安装说明、常见问题和自定义皮肤/词库说明见 [完整使用文档](Assets/README.md)。
